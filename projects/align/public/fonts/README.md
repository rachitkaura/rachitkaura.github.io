# Local font assets

Align serves its existing DM Sans and Manrope families locally to avoid a third-party stylesheet request. Both variable WOFF2 files use `font-display: swap`; system fallbacks remain available.

| --- | --- | --- | --- |
| DM Sans | `@fontsource-variable/dm-sans` | 5.3.0 | SIL Open Font License 1.1; see `dm-sans-LICENSE.txt` |
| Manrope | `@fontsource-variable/manrope` | 5.3.0 | SIL Open Font License 1.1; see `manrope-LICENSE.txt` |
